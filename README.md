# 🚨 Emergency Report Management System

A Full Stack Emergency Report Management System that enables citizens to report emergency incidents in real-time while allowing administrators to verify, manage, and monitor reports through an interactive dashboard.

Built using **React.js**, **TypeScript**, **Spring Boot**, **Java**, **MySQL**, **JWT Authentication**, and **Leaflet Maps**.

---

## 📌 Features

### 👤 User Features

- User Registration & Login (JWT Authentication)
- Secure Profile Management
- Report Emergency Incidents
- Upload Incident Images
- View Personal Reports
- Track Incident Status
- Live Location using Leaflet Maps
- Dark Mode Support
- Responsive UI

---

### 👨‍💼 Admin Features

- Admin Dashboard
- View All Incidents
- Approve/Reject Reports
- Delete Reports

- Analytics Charts
- User Management
- Search & Filter Incidents

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/M-DhirajS/Emergency_Report_Management_System.git
```

---

## Backend Setup

```bash
cd backend
```

Configure MySQL Database inside

```
application.properties
```

Example

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/emergency_alert_db

spring.datasource.username=root

spring.datasource.password=your_password
```

Run Backend

```bash
mvn spring-boot:run
```

Runs on

```
http://localhost:8080
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Runs on

```
http://localhost:5173
```
